# Chi Myaku no Kōya

Projeto original de anime/donghua brasileiro para o mercado global, com foco em clãs, território de fronteira, código de honra e narrativa cinematográfica.

## Sobre o projeto

Este repositório organiza a obra original, seus personagens, episódios, universo, prompts visuais e materiais de produção.

## Estrutura

- `docs/` — documentação geral do projeto.
- `worldbuilding/` — universo, clãs, leis e território.
- `characters/` — fichas dos personagens.
- `episodes/` — sinopses e roteiros dos episódios.
- `prompts/` — prompts para imagem, vídeo e som.
- `assets/` — imagens, referências e arquivos de apoio.

## Como usar

1. Abra a pasta do projeto.
2. Leia os arquivos em `docs/`.
3. Use os prompts em `prompts/`.
4. Edite os episódios em `episodes/`.

## Objetivo

Desenvolver uma obra original pronta para produção, publicação e monetização legal.

## Status

Em desenvolvimento.

## docs/overview.md

```md
# Visão geral

Chi Myaku no Kōya é uma obra original de anime/donghua ambientada em um território de fronteira regido por um código de sangue.

## Premissa

Um herdeiro relutante retorna ao território da família e descobre que a herança não é riqueza, mas liderança, conflito e responsabilidade.

## Temas

- Sangue e escolha.
- Código e caos.
- Família e poder.
- Herança e identidade.
- Território, honra e sobrevivência.

## Tom

Cinematográfico, histórico, dramático e consistente.
```
